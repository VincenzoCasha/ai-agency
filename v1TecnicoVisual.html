            Instrucciones para Opus

            Como actualizar este roadmap

            1. Lee primero V1Tecnico.md, seccion 0.1 Estado vivo del proyecto, y despues este archivo.
            2. Al terminar una sesion, actualiza el objeto roadmapState dentro de este HTML.
            3. Sincroniza los mismos cambios en V1Tecnico.md: fase actual, progreso, implementado, pendiente, bloqueos y registro.
            4. No marques una fase como DONE sin build/tests/verificacion.
            5. Si el codigo real contradice este HTML, corrige este HTML y deja nota en el registro de sesiones.
