# CRUDO — Guía del Admin para el Owner

Esta guía explica cómo usar el panel de administración de CRUDO desde el móvil.
**Tiempo medio al día: menos de 5 minutos.**

> El admin está diseñado para una sola persona. No necesitas conocimientos técnicos.

---

## Acceso

1. Abre el navegador del móvil y ve a `crudo.es/admin` (o la dirección que te enviemos).
2. Introduce tu email y contraseña.
3. Ya estás dentro.

---

## Rutina de mañana (≤ 90 segundos)

Al abrir el bar, revisa si hay pedidos nuevos:

1. Entra en **Pedidos** → verás los nuevos en la parte superior.
2. Por cada pedido: confirma o cancela con un toque.
3. El cliente recibe el WhatsApp de confirmación automáticamente.

---

## Rutina de cierre (≤ 90 segundos)

1. Entra en **Pedidos** → marca como recogidos los que ya se entregaron.
2. Si hay productos agotados: entra en **Catálogo** → busca el producto → toca "Agotado".
3. Si el día ha sido muy intenso y no puedes asumir más pedidos: activa el **Kill switch de pickup** (ver abajo).

---

## Rutina semanal (≤ 10 minutos)

1. **Actualizar catálogo de temporada:** entra en **Catálogo** → activa/desactiva quesos según lo que tengas esa semana.
2. **Revisar consultas:** entra en **Consultas** → responde o archiva los mensajes pendientes.
3. **Revisar reservas de eventos:** entra en **Eventos** → confirma los asistentes pendientes.

---

## Gestionar pedidos pickup

- **Ver pedidos:** Pedidos → lista ordenada por fecha de recogida.
- **Confirmar:** toca el pedido → "Confirmar" → el cliente recibe WhatsApp.
- **Listo para recoger:** cuando tengas la tabla preparada → "Listo".
- **Recogido:** cuando el cliente haya pasado → "Recogido".
- **Cancelar:** solo si no puedes servir el pedido → añade nota para el cliente.

---

## Marcar producto agotado

1. Catálogo → busca el producto (por nombre).
2. Toca el producto → estado de stock → selecciona "Agotado" o "Pocas unidades".
3. Guarda. La web se actualiza al momento.

---

## Kill switch de pickup

Si un día tienes demasiados pedidos o no puedes atender más:

1. Ajustes → **Pausar nuevos pedidos de pickup** → activa el interruptor.
2. La web mostrará automáticamente: *"Hoy no admitimos más pickups, vuelve mañana."*
3. Cuando puedas retomar, vuelve a Ajustes y desactívalo.

---

## Crear o editar un evento

1. Eventos → "Nuevo evento" (o toca uno existente para editarlo).
2. Rellena: título, fecha, precio(s), capacidad, descripción.
3. Sube la foto del cartel.
4. "Publicar" → el evento aparece en la web.

---

## Revisar consultas (contacto / mayoristas)

1. Consultas → verás todos los mensajes recibidos.
2. Toca uno para leerlo completo.
3. Responde por email o WhatsApp directamente desde tu teléfono.
4. Marca como "Atendido" cuando hayas respondido.

---

## Gestionar reservas de eventos

1. Eventos → toca el evento → "Reservas".
2. Verás la lista de asistentes con nombre, email y número de personas.
3. Confirma o cancela cada reserva con un toque.

---

## Preguntas frecuentes

**¿Puedo usar el admin desde el ordenador?**
Sí, funciona en cualquier navegador. Pero está diseñado para móvil.

**¿Qué pasa si pierdo la contraseña?**
Contacta al equipo técnico para que te la reseteen.

**¿Los cambios en el catálogo son inmediatos?**
Sí, se actualizan en la web en segundos.

**¿Puedo tener varios admins?**
En V1 solo hay un usuario admin. Soporte para staff en V2.
