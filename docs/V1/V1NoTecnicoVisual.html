    Estado vivo

    Como actualizar este HTML

    1. Actualiza el objeto nonTechState al final de cada sesion de negocio, contenido, legal o launch.
    2. Usa los estados TODO, DOING, BLOCKED, REVIEW, DONE y NEXT (siguiente).
    3. No marques nada como DONE si no hay entregable real: decision escrita, archivo recibido, cuenta creada, copy aprobado o checklist validado.
    4. Si cambia una decision importante, actualiza tambien docs/V1/V1Tecnico.md si afecta al equipo tecnico.
    5. El array technicalBackbone se sincroniza con la tabla §0.1 de V1Tecnico.md (verdad tecnica).
